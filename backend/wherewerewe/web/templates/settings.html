Connect

In Tautulli, open Settings → Notification Agents → Add a new notification agent → Webhook. Use the URL below with method POST, turn on the Playback Start, Playback Stop and Watched triggers, and paste the JSON as the data for all three.

{
  "action": "{action}",
  "media_type": "{media_type}",
  "user_id": "{user_id}",
  "username": "{username}",
  "rating_key": "{rating_key}",
  "grandparent_rating_key": "{grandparent_rating_key}",
  "season_num": "{season_num}",
  "episode_num": "{episode_num}"
